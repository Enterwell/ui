# ConfirmButton

## Description

<ComponentDescription name="ConfirmButton" libraries={["MUI"]} />

### Parameters

{/* <ComponentParameters name="ConfirmButton" /> */}

`children` is the visible trigger-button label. `header`, `message`, `color`, and
`confirmButtonText` provide defaults for the dialog. `onConfirm` is optional and
runs after confirmation; cancelling only closes the dialog.

Use `slotProps.dialog` to configure the dialog, including its `children`, button
labels, and size. These props override the top-level dialog defaults. Use
`slots.dialog` to provide a replacement component accepting `ConfirmDialogProps`.

`ConfirmButton` owns the dialog's open state and supplies `isOpen`, `onConfirm`,
and `onCancel`. Those three props cannot be configured through `slotProps.dialog`.

## Migrating dialog configuration

`slots.dialog` now accepts a component instead of a props object. Move existing
dialog configuration to `slotProps.dialog`:

```tsx
// Before
<ConfirmButton
    header="Confirm deletion"
    onConfirm={handleDelete}
    slots={{ dialog: { cancelButtonText: 'Keep item' } }}
>
    Delete item
</ConfirmButton>

// After
<ConfirmButton
    header="Confirm deletion"
    onConfirm={handleDelete}
    slotProps={{ dialog: { cancelButtonText: 'Keep item' } }}
>
    Delete item
</ConfirmButton>
```

Wrappers that merge a default cancel label should also move that merge:

```tsx
slotProps={{
    ...slotProps,
    dialog: { cancelButtonText: 'Keep item', ...slotProps?.dialog },
}}
```
